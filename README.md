### 📌 Projetos em destaque

**[Ebola na África Subsaariana](https://github.com/analuizabotelho/eda-ebola-africa-subsaariana)**
Análise exploratória de dados e data storytelling com 1.200 registros semanais de 7 países: auditoria e tratamento dos dados, correlações, teste t e relatório executivo com plano de ação. Projeto em grupo.
`Python` · `Pandas` · `Seaborn` · `SciPy`

**[GlassRoof](https://github.com/RyanHangai/glassroof)**
Projeto de BI com dados eleitorais do TSE (eleições de 1996 e 2016 em São Paulo): staging e views em T-SQL no SQL Server, modelo de dados e dashboard no Power BI para responder a 6 perguntas de negócio. Projeto em grupo.
`SQL Server` · `T-SQL` · `Power BI` · `DAX`

**[Monitoramento de TI](https://github.com/analuizabotelho/eda-monitoramento-ti-infra)**
Análise exploratória de métricas de servidores (latência, CPU e memória) para apoiar uma decisão de investimento em hardware.
`Python` · `Pandas` · `Seaborn`

**[EduTrack](https://github.com/analuizabotelho/edutrack)**
App de agenda e organização acadêmica para estudantes. Atuei na modelagem do banco de dados no Xano, no desenvolvimento de CRUDs e no debugging em XanoScript. Projeto em grupo.
`Streamlit` · `Xano` · `Python`

**[CHEFEDEBAR](https://github.com/analuizabotelho/chefedebar)**
MVP web mobile-first para bartenders e entusiastas de coquetelaria: catálogo de coquetéis, destilados e xaropes, busca global, favoritos e calculadora de proporções (Super Juice). Modelagem de dados, escopo e condução do projeto de minha autoria; front-end desenvolvido com apoio de IA (Claude).
`Xano` · `Banco de dados`
